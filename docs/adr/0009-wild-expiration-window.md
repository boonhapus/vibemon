# Wild Vibemon expire after 30 days without encounter

Wild Vibemon are removed from play when their last actual encounter is more than 30 days old, using wild-pool entry time as the initial timestamp before the first encounter. Any real player encounter resets this clock globally, regardless of which trainer encountered it and regardless of whether the Vibemon is adopted. Trainer-specific encounter adjustments affect selection odds only; they do not drive expiration. The same rule applies regardless of whether the wild Vibemon came from rejected candidate generation or prior trainer ownership. Release resets this expiration clock to the release time so giving up an owned Vibemon cannot behave like immediate deletion. Expiration marks the Vibemon as **Expired** instead of immediately deleting persisted rows or assets, and **Expired** is terminal for normal gameplay; asset cleanup is separate retention work so storage deletion failures cannot block the domain transition. This bounds the wild pool without expiring creatures based on invisible encounter-roll opportunities, and it preserves Vibemon that players are actually seeing.
