# Unresolved shown candidates become wild

A candidate that has been successfully christened and shown to a trainer consumes its generation credit and must not remain in ambiguous review state forever. During review it is visible only to the reviewing trainer and is not eligible for the wild pool, but it does not block the trainer from sequentially generating another candidate if they have remaining daily credits. The timeout starts when the candidate is successfully shown, not when generation starts. If the trainer leaves it unresolved for 24 hours, it becomes **Wild**; player-facing copy can describe this as the Vibemon running away. The deadline is authoritative even if cleanup runs late: adoption after the deadline is rejected and first resolves the candidate to Wild. The 24-hour window aligns with the daily generation-credit cadence while giving the trainer a reasonable chance to recover from app closure or connectivity issues.
