# Wild encounter outcomes adjust trainer-specific weight

Candidate rejection, timeout, and normal wild encounter outcomes share one trainer-specific encounter adjustment model. Candidate rejection and timeout start at `0.00x`; run starts at `0.30x`; defeat starts at `0.50x`; win starts at `0.75x`. Each adjustment continuously decays back to normal over a randomly assigned 1-3 day window. Catching mechanics are deferred and are not influenced by win, defeat, or run. If a new adjustment occurs for the same trainer/Vibemon pair before the previous one finishes decaying, the latest outcome replaces the previous adjustment rather than compounding. Adoption clears or ignores that trainer/Vibemon adjustment because the mon is no longer selected for that trainer through wild encounters; release starts fresh wild weighting. Encounter adjustments are trainer-specific and do not affect other trainers. These outcome weights are tuning constants, and every actual encounter still resets the wild expiration clock.
